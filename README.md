A chess engine in 2,608 bytes of Python: alpha-beta search at a fixed 100k nodes per move, transposition tables, null-move pruning, late-move reductions, killers and history, quiescence with check evasions. Mean Elo 1461 on practice trials — above the 1365 house baseline.

## Run it

```sh
MAKEFUN_ENV_URL=<env-url> python3 main.py
```
